THE GODPOSTER is an offline web app that turns a person's own photos into multi-panel GTA 6-style cover art. It offers seven panel layouts and six colour grades (including the Omerta noir grade), adds giant gradient title lettering with a script subtitle, per-panel caption chips and starring names, plus a family seal and a wanted-stars badge. Finished posters export as PNG at 1080x1080, 1080x1350 and 1920x1080.

## What's inside

- Seven layout templates, from a single hero shot to dense multi-panel collages.
- Six colour grades, each tunable with strength, contrast, saturation, grain and vignette sliders.
- Per-panel photo control: drag, zoom and recentre each image inside its frame.
- Editable caption chips, starring names, family seal and wanted stars.
- One-click export of all three PNG sizes.

## Run it

Run `node serve.ts` from the repository root and open the address it prints (or serve the `app/` folder with any static file server). The app runs fully offline.
